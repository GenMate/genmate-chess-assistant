Your token

The extension stores your token and settings in this browser only (not synced). A token saved by version 1.1.0 may also remain in Firefox Sync storage. “Remove token” in the toolbar popup deletes the local token and requests removal of the old Sync copy. Removing it from the extension does not revoke it on Lichess.

Extension news

The extension checks a small news file hosted on GitHub every few hours by default. These requests contain no token, game or browsing data. Unread news can be dismissed in the popup. Each news item produces at most one system notification.
